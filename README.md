## Cara Deploy ke GitHub Pages (2 menit)
1. Buat repo baru di GitHub, contoh: resto-cobek
2. Upload file index.html ini ke repo (drag & drop di web GitHub)
   - Atau extract ZIP ini lalu upload index.html + README.md
3. Di repo > Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Save
4. Tunggu 1-2 menit, website live di: https://USERNAME.github.io/resto-cobek/
